# stop-phrase-guard

`Stop` hook that blocks the turn from ending when the last message contains ownership-dodging or session-quitting phrases. Patterns and corrections live in [`scripts/stop-phrase-guard.sh`](scripts/stop-phrase-guard.sh).

Forked from [benvanik's `stop-phrase-guard.sh`](https://gist.github.com/benvanik/ee00bd1b6c9154d6545c63e06a317080) via [LITl-l's portable adaptation](https://github.com/LITl-l/dotfiles/blob/main/claude/stop-phrase-guard.sh).
